The First Hundred is how the collective opened to contributors: a hundred real tasks, across four projects, each scoped for one person. There are no prizes, just useful work on technology that serves Muslims, done in the open.

The live board is at [bytheitc.xyz/first-hundred](https://bytheitc.xyz/first-hundred). It shows every task, which are taken, and which are done.

## The projects

| Project | Language | Tasks |
|---|---|---|
| [Ijaazah](/products/ijaazah) | Go | signed chains of ijazah: the spec, a browser verifier, QR scanning, a public register |
| [Khutbah](/products/khutbah) | Python | Qur'an quotation matching: transliteration, subtitles, other riwayat, evaluation |
| [Hifz Trail](/products/hifz) | TypeScript | offline use, reminders, an adaptive scheduler, reciting from memory |
| [Zakat Kit](/products/zakat) | TypeScript | more currencies and bank formats, shares and harvests, business tools, eligibility proofs |

## How a task works

1. **Find one** on the board, or on GitHub with the label [`first-hundred`](https://github.com/search?q=org%3Abytheitc+label%3Afirst-hundred+is%3Aopen&type=issues).
2. **Claim it** on the portal, so no one else starts the same thing. See [Contributing](/contributing).
3. **Open a pull request** that closes the issue.
4. **A maintainer merges it**, and the board counts it.

## Suggesting a scenario

Zakat Kit needs real situations to test against: unusual assets, mixed currencies, debts that are hard to classify. If you have one, open an issue on [bytheitc/zakat](https://github.com/bytheitc/zakat/issues) describing it (no real figures needed). Scenarios become test cases.
